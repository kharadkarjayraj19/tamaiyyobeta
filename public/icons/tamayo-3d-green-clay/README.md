# Tamayo Icon Set G (Green Clay 3D)

Reference-aligned set inspired by clay 3D icons with consistent green palette.

## Visual language

- Rounded-square clay badge base
- Green primary + dark green secondary
- Soft depth (extrusion + floor shadow)
- Subtle warm metallic accent where needed
- 32x32 canvas, transparent background
